**LangGraph + MongoDB + Astra DB (RAG) + Gemini + Streamlit**
 
An agentic fitness coach built with production-grade engineering: a LangGraph ReAct loop with structured Pydantic schemas for tool calls, full observability and tracing via **Langfuse**, retry/fallback handling for LLM API failures, per-user auth scoped through context variables, and token-usage optimization across the context window.
